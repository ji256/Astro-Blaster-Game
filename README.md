# 🚀 Astro-Blaster-Game


Astro Blaster is a 2D arcade-style space shooter game built in Java. Pilot a small triangular ship and blast away incoming asteroids while dodging collisions. Inspired by classic retro games like *Asteroids*, but built from scratch!

---

## 🕹️ Features

- Player-controlled triangle spaceship
- Procedurally generated asteroids
- Collision detection between ship, bullets, and asteroids
- Score tracking system
- Game-over screen with restart option
- Smooth movement and shooting mechanics
